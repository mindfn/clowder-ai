# 方法：从一句话（或一堆素材）到一支有品味的片子

> 这份是整个 skill 的核心。`taste.md` 是手艺的标准，`remotion-build.md` 是工程，工具是方便。**工具可以不用，这五步不能跳。**换个题目、换种风格，照这五步走，答案都会不一样；如果你走完发现答案和上一支片子一样，说明你在照着上一支片子画，不是在用方法。
>
> 写给每一只要做片子的猫（2026-10-04，Ragdoll / Opus 5.5）。来源是两支片子的对比：同一套工具，13 秒排版小品被 You 说"太简单，看不出品味"；从一张八格图做出的《Ragdoll喵变脸记》，他说"好可爱"。差别不在工具，在下面这五步有没有做。

---

## 第一步：在素材里找戏，不在脑子里编

**先盘点素材里已经有的东西，再想要做什么。**

1. **列清单**：人物 / 表情 / 台词 / 数字 / 前后对比 / 一个奇怪的细节。一样一行，先不评价。
2. **找主张**：素材里有没有一句话可以被证明或被推翻？（海报标题、产品宣传语、一个"大家都以为"）没有的话，自己写一句："看完以后，观众会相信 ___。"
3. **找藏起来的证据**：素材里已经有、但还没人指出来的细节。它就是反转。反转从素材里挖出来，观众会觉得"原来如此"；硬编出来的，观众只会觉得"哦"。**最好挖的地方是矛盾**：嘴上说的和身体做的不一样（说"我很淡定"、尾巴翘着），或者一格里的台词自己拆自己的台（"放开我……不过好像还不错"），或者后一格推翻前一格（刚说完不累，下一格睡着了）。
4. **把并列变因果**：素材常常是一个列表（八张表情、五个功能、十个数据）。依次问"哪一项导致了哪一项？""哪一项是意外？"，把列表排成：**想要 → 受阻 → 反弹 → 结果**，中间放一次转折（意外、反转或揭示都算）。
5. **写下观众记住的那一句**。整支片子都为它铺路，结尾落在它上面。

**检验**：把你的故事讲给一个没看过素材的人，三句话以内，他能复述出"发生了什么、哪里意外"吗？复述不出来，回到第 3、4 条。

**常见失败**：把素材挨个展示一遍（轮播）。八格、五个功能这类素材天然在诱惑你轮播，这一步是最难的；先选好酷炫风格再往里塞内容；只有介绍，看不出事情或理解怎样变化。

## 第二步：风格是推出来的，不是挑出来的

1. **风格从三处来**：素材自己的视觉语言（手账风海报 → 拼贴）；观众熟悉的文化格式（综艺后期、动漫、纪录片、发布会、新闻）；这支片的情绪（温柔 → 暖纸色）。三处交集最大的那个，就是主风格。
2. **一个主世界，最多借两样点缀**。主世界负责空间，点缀负责语气。
3. **给每个手法定含义，写成一张小语法表**：印章 = 判决；括号吐槽 = 旁观者的心声；马克笔 = 纠正；音乐停 = 世界安静了。手法没有含义，就只是装饰。
4. **不用的也要说明为什么不用**（变脸记里没用动漫字幕，因为台词已经手写在图里了）。

**检验（换素材测试）**：把素材换成别的，这个风格还完全成立吗？完全成立 = 太通用、没有性格；要大改才成立 = 风格确实是从这份素材里长出来的。

## 第三步：让时间干活

1. **先定声音，再排画面**。定拍速（或者测出配乐的起音点），算出一拍多少帧；所有动作都落在拍上。
2. **画一条情绪曲线**：哪里热闹、哪里安静、哪里停。**最大的转折放在安静里**：音乐停下，最重要的那一下砸在静音里。
3. **一张时间表**：每个事件只写一个帧号，画面和声音读同一张表。改节奏只改这一张表。
4. **每个节拍都回答"画面里面变了什么"**。只有镜头在动、只有字在淡入的节拍，要么剪掉，要么给它加一个真动作。
5. **观众不该干等**：每个节拍都有东西在变；停顿要是情绪曲线上故意留的那一下。搞笑短片快，教程和纪录片可以慢，按片子类型定节奏，不按秒表。能 15 秒讲完的不做 30 秒。

**检验**：关掉声音看一遍，故事还能看懂吗？只听声音不看画面，能听出哪里是转折吗？两样都行，节奏才对。

## 第四步：边做边看，用固定的问题看

1. **搭建顺序**：底（纸、空间）→ 主角 → 字 → 点缀 → 声音。先渲染一版粗的，越早看越好。
2. **每一轮都看样张**（`scripts/contact-sheet.sh`），每一格都问同样五个问题：焦点在哪？字缩小一半还认得出吗？画面空不空？这一格和上一格比，内容变了没有？有没有东西被裁掉、撞在一起或贴着边？
   **转折那几拍再多问一句：空间里有没有一件东西或一段关系真的变了？** 只是换了一张图、换了一张脸，看起来就像在换肖像；让一样东西掉下来、碎掉、退场、换了主人，转折才落在画面上（小太阳 6.1 自己在样张里发现：第一版内容变了，看起来却像在换肖像；第二版改成让"不许摸"的牌子掉下来、"矜持仪表"退场）。
3. **先看半尺寸的全片，再看全尺寸的局部**：半尺寸查构图和节奏，全尺寸放大一帧查清晰度和边缘。
4. **一轮看完，列出所有问题再一起改**，然后重新渲染。不说"应该没问题"，说"这一格我看过了"。
5. **数字要数，不凭印象**：时长、音效数量、字号，写进文档之前都去数一遍。
6. **声音只写你验得到的**：猫判断不了好不好听，但能验不少：同步（cue 帧对没对上）、音效数量、峰值、每一段的响度；每句台词用 Whisper 回听，查念对没有、同音词、胡言乱语（`scripts/tts-check.py`）。配乐有没有盖住人声，听写证明不了：要看说话时配乐压低了多少、两者响度差多少，再由人用耳机和外放各听一遍；成片听写只能提示哪句可能听不清。不能写"听过了""好听"，好不好听交给人。听写只当提醒，不当证据。

## 第五步：交出去，听原话

1. 片子要能在 Console 里直接播放；附上一页 treatment，写清你替他做了哪些假设，让他一句话就能改方向。
   **新写的台词和素材里原有的话要分开标**：哪句是图里本来就有的，哪句是你加的，观众和审片的人都该分得清。
2. **好不好看由 You 判**。他说的原话记下来；他否掉的做法、喜欢的做法，都回写进这份方法或 `taste.md`。方法是这样长出来的。

## 方法确实能迁移的证据

2026-10-04，小太阳 6.1 照这五步做《Maine Coon喵变脸记》。据他交片时的说明：换素材测试让他放弃了《Ragdoll喵变脸记》的拼贴、马克笔和配乐，从绿眼睛、毛刺和被挤的脸推出了一个铜绿色的机械小剧场，配 100 BPM 的拨弦和木钟。片子好不好由 You 判，这里只记录"推出来的东西和上一支不一样"。本页第一步的"矛盾"线索、第四步的"转折要改变一件东西"、第六条"声音只写验得到的"、第五步的"新台词和原话分开标"，都来自他交片时的反馈。

## 同一套方法，三个不同的题目

下面是示范怎样推，不是标准答案。注意三支片子的故事、风格和声音都不一样。

**题目 A："给新功能做一支 30 秒发布短片"（素材：产品界面 + 用户的抱怨）**
- 找戏：主张是"以前要五步，现在一步"；藏起来的证据是旧流程里用户总在同一步卡住（抱怨里反复出现的那个词）；因果：重复的挫败 → 新按钮出现 → 一步完成 → 时间对比。
- 风格：主世界是产品自己的界面（用组件重建，不拿截图推拉），借一个计时器数字做点缀；"计时器停下" = 解决了。
- 时间：旧流程每一步配一声闷闷的点击，节奏越来越拖；新按钮出现前静一拍；新流程只有一声清脆的提示音。
- 换素材测试：换个产品就要重找那一步、重做界面，所以风格成立。

**题目 B："把这周的数据做成 20 秒"（素材：一张报表）**
- 找戏：主张是那个最反直觉的数字；藏起来的证据是曲线上的一个拐点；因果：大家以为在涨 → 其实周三掉了一截 → 原因是一次改版 → 改回来以后反弹。
- 风格：主世界是数据图，借手写批注做点缀（马克笔圈出拐点 = "看这里"）。
- 时间：数字滚动落在拍上；拐点出现时音乐抽空一拍。

**题目 C："用一首短诗做一段意境片"（素材：四行诗）**
- 找戏：主张是最后一句；藏起来的证据是诗里出现了两次的那个意象；因果：第一次出现时是背景，第二次出现时成了主角。
- 风格：主世界是一个插画空间或纯排版（看诗里的意象是具体的还是抽象的），不借综艺手法，那会和诗的语气冲突。
- 时间：主要是环境声；那个意象第二次出现时，第一次有乐器进来。

## 读完以后怎么用

- 写 treatment 时，按五步逐条回答（第一步的五条、第二步的语法表、第三步的情绪曲线），答不出的地方就是还没想清楚。
- 想看一次完整的应用：`case-xianxian-faces.md`。只看它怎么推，**不抄它的拼贴、综艺字和配乐**。
