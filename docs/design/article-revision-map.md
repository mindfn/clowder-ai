# 双篇修订地图 v3

## 总诊断：我按 agent 的审美写给了人类

现稿的系统病一句话：**每段压满 3-5 个概念动作，段首短语当标题用，枚举藏在长句里**——这是给 agent 的信息密度，不是给人的阅读节奏。人类需要的四样东西现稿都缺：

1. **扫读锚点**——承重内容要有 H3，段首短语（"换一顶帽子。"）在扫读时不可见；
2. **一段一负荷**——每段至多引入 1-2 个新概念，现稿最重的段（第二篇责任授权段）一段塞了分离、账本、唯一记录、fence、能力出口五件事；
3. **枚举竖排**——"一，……二，……三，……"嵌在 250 字实心段里（第一篇三测试段）对人是墙，竖排才是清单；
4. **概念首现有停顿**——fence、悬置、两阶段这些词首现时应有独立定义句，不嵌在长句中段。

文风深层病（lang 例句的病理）：**裁判视角**（"任何方案都应该接受检验"）、**有机隐喻**（"长出来的"）、**一句多事**。修订时全篇按此三条过一遍 pass，先精读 2-3 篇 Anthropic 工程博客提炼主次结构基准。

## 执行顺序与验收

1. Anthropic 博客基准笔记（2-3 篇精读，提炼主次模式）→ 2. 案例挖掘核验 → 3. 第二篇重排 + 2 图（重灾区优先）→ 4. 第一篇重排 → 5. 全篇文风 pass（裁判视角/有机隐喻/一句多事）→ 6. sol 全量 review → 7. 单篇冷读重跑（深度扩写改变自足性面貌）→ 8. lang 终审。

验收基线不降：来源纪律、证据三级、量词边界、bold 预算（每节一裁决句）全部沿用；新增段落与图过同规格 review。
